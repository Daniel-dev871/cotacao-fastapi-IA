# Consulta e Exportação de Cotações de Moedas em Python

Projeto prático desenvolvido para consumo de APIs REST, manipulação de dados em formato JSON e tratamento de exceções em Python.

## Funcionalidades
- Consulta a cotação de moedas em tempo real através da API pública AwesomeAPI.
- Suporte a moedas dinâmicas via terminal (USD, EUR, BTC, etc.).
- Exportação automatizada dos dados tratados para arquivo `relatorio_cotacao.json`.
- Tratamento de erros de conexão e entradas inválidas.

## Tecnologias Utilizadas
- **Python 3.13**
- **Requests**: Para chamadas HTTP.
- **JSON**: Para manipulação e geração do relatório local.
